🛒 AutoMarket PWA - O CFO de Bolso para Varejo Autônomo

O AutoMarket é uma ferramenta Progressive Web App (PWA) de alta performance, desenvolvida para transformar a gestão de compras e precificação de minimercados autônomos. Ele atua como um Diretor Financeiro (CFO) portátil, garantindo margem de lucro real na ponta do dedo.

🚀 Funcionalidades Principais

🧠 Inteligência Financeira (CFO Mode)

Cálculo de Lucro Líquido Real: Considera todas as variáveis ocultas que corroem a margem:

Taxas de Licenciamento (Franquia).

Taxas de Meio de Pagamento (Crédito, Débito, PIX, Voucher).

Impostos (Regime ME ou MEI).

Custo Fixo Diluído: Calcula o impacto exato do aluguel, luz, internet e sistemas em cada produto vendido.

Simulador de Cenários: Alterne instantaneamente entre [PIX], [CRÉDITO] e [VOUCHER] para ver como o lucro muda dependendo de como o cliente paga.

📱 Operação de Campo (Scanner Offline)

Offline-First: Funciona 100% sem internet dentro de atacados (zonas de sombra).

Scanner Nativo: Leitura de código de barras via câmera do celular.

Single File Workflow: Manipulação direta de planogramas (.xlsx e .csv) sem necessidade de integrações complexas (API) ou riscos de scraping.

🛡️ Segurança e Proteção de Receita

Sessão Única (Anti-Carona): Impede o compartilhamento de senhas. Se uma conta for acessada em um segundo dispositivo, o primeiro é desconectado imediatamente.

Kill Switch Remoto: Permite o bloqueio instantâneo de usuários inadimplentes via painel administrativo.

Zero Backend de Dados: Os dados sensíveis da loja (preços, estoque) são processados exclusivamente no dispositivo do usuário (Client-Side), garantindo privacidade total.

🛠️ Como Usar (Fluxo Simplificado)

Acesse: Abra o App via navegador ou instale na tela inicial.

Configure: Preencha seus custos fixos e taxas na aba de Configurações (o App memoriza).

Carregue: Suba seu arquivo de Planograma (.xlsx) exportado do sistema.

No Mercado:

Bipe o produto.

Digite o preço da etiqueta da gôndola.

Veja o Semáforo de Lucro (Verde/Amarelo/Vermelho).

Finalize: Gere o arquivo de importação atualizado e suba no seu sistema de gestão.
